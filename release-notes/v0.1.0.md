LaküenRecomp v0.1.0 — the first numbered build of this fork of [NotRexed/Hookshot](https://github.com/NotRexed/Hookshot), tuned for Linux on AMD RDNA2 GPUs (desktop RX 6000 cards, Steam Deck, Legion Go S). Versions count up below 1.0 until everything runs as it should on all three.

This release contains no game data, keys or executables: the AppImage is the builder, which builds the game on your PC from your own copy. All of the recompilation work is NotRexed's and the Hookshot contributors'.

## What is in it

- **RDNA2 on RADV:** task and mesh draws on the compute path; the shader optimizer stays on.
- **Low-end GPU defaults (dedicated cards of 8 GB or less):** the VRAM compaction held at 90% instead of 85%, and a 512 MB render target pool that keeps 128 MB while VRAM is short. On an 8 GB RX 6600 XT in the field: 30-60 fps where it was 7-27.
- **Handhelds:** handheld settings and texture limits on first start; the VRAM compaction stays off on integrated GPUs.
- **Steam / Gaming Mode:** the game's own SDL2 under Steam (Steam Controller buttons and left stick), controllers count whatever window has the focus, the launcher waits for the game.
- **Valve controllers without Steam:** their gyroscope is off by default (the camera no longer drifts up).
- **Sound:** a 30 ms output cushion and clock-drift control against crackles.
- **Builder:** dark native file choosers, lower build priority (the PC stays usable), named LaküenRecomp.
- **Upstream:** synced with NotRexed/Hookshot `bce1476`, plus #2133 (Fritchii's pipeline list), #2452 (bosses drawn blue in their first cutscene) and #2451 (crash after loading a save).

Every change can be switched off with an environment variable in `hookshot_env.txt`; the [readme](https://github.com/elkarbeenus/Hookshot_own-fork#what-is-changed) lists them.

## Install

1. Download `LakuenRecomp-v0.1.0-x86_64.AppImage` below, `chmod +x` it and start it.
2. Choose your game files and a folder, then build. An existing folder is updated in place; saves stay in `~/.local/share/hookshot`.
3. In Steam (Gaming Mode), add the AppImage as a non-Steam game; `--play` as a launch option starts the game directly.
