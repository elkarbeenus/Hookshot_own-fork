LaküenRecomp v0.3.0 is **one build for a PC, the Steam Deck and the Legion Go S**. It brings this fork up to date with [NotRexed/Hookshot](https://github.com/NotRexed/Hookshot) (`9b6072cd`) and merges the handheld line into the main one: every handheld or PC change decides by the device at each start.

This release contains no game data, keys or executables: the AppImage is the builder, which builds the game on your PC from your own copy. All of the recompilation work is NotRexed's and the Hookshot contributors'.

## Device profiles

- The builder recognises the device and offers its recommended settings once: **Yes** applies them, **No** keeps your own, **Cancel** asks next time. Started from Steam, the question comes before the game.
- **Device profile** on the launcher's page applies the profile of any of the three devices, or restores your settings from before (they are always kept first).
- A profile is a small file in the builder (`profiles/<device>.ini`); when a release changes one, the builder offers it again.

| Device | Game profile | Render resolution | Output | Frame generation |
|---|---|---|---|---|
| Steam Deck | Handheld | 50 % | – | 2x, paced |
| Legion Go S | Handheld | 67 % | – | 2x, paced |
| PC with a graphics card of 8 GB or less | Docked | 75 % | 1920x1080 | 2x, paced |

## Handhelds (AMD integrated GPUs)

- **Handheld picture:** settings kept from an older version that still say Docked switch once to the game's Handheld profile (1536x864 instead of 2304x1440 for a handheld screen). The game's log says which profile it starts with.
- **RAM:** textures at most 2 GB on 16 GB of shared memory; when less than 1.5 GB of RAM is free the textures give up the difference (never below 1 GB), where a Steam Deck had filled RAM and swap and dropped to 1-2 fps. Upload memory stays allocated instead of being made again in every area change (freezes of up to several seconds before).
- **Shadows** are drawn at half size. `LAKUEN_SHADOWS=0` in `hookshot_env.txt` turns them off, `LAKUEN_SHADOW_SCALE=1` brings back the original size.
- The game's code is tuned for the Legion Go S's Zen 3+ cores, as it already was for the Steam Deck's Zen 2.

## PC (graphics cards of 8 GB or less)

- Output 1920x1080 and a fixed 75 % render resolution once where the settings say the game's own output and Auto: at 2560x1440 the textures had too little room left and were reloaded constantly.
- Less texture churn when VRAM is short (only the excess goes, [#2826](https://github.com/NotRexed/Hookshot/pull/2826)), smaller game-memory imports ([#2685](https://github.com/NotRexed/Hookshot/pull/2685), [#2825](https://github.com/NotRexed/Hookshot/pull/2825)), render targets reused instead of made again.

## From upstream

- Fewer idle threads spinning ([#2709](https://github.com/NotRexed/Hookshot/pull/2709)), bounded waits for shaders still translating ([#2586](https://github.com/NotRexed/Hookshot/pull/2586)), the pipeline cache warmed at the first start after a build ([#2865](https://github.com/NotRexed/Hookshot/pull/2865), [#2869](https://github.com/NotRexed/Hookshot/pull/2869)), faster per-draw caches ([#2774](https://github.com/NotRexed/Hookshot/pull/2774)), native float atomics ([#2306](https://github.com/NotRexed/Hookshot/pull/2306)), scene-change memory surges kept down ([#2467](https://github.com/NotRexed/Hookshot/pull/2467)), shadow resolution option ([#1892](https://github.com/NotRexed/Hookshot/pull/1892)), and many fixes.

## Install

1. Start your LaküenRecomp builder and press **Update**, or download `LakuenRecomp-v0.3.0-x86_64.AppImage` below, `chmod +x` it and start it.
2. An existing game folder is updated in place; saves stay in `~/.local/share/hookshot`. The builder then asks about the device profile.

Every change can be switched off with an environment variable in `hookshot_env.txt`; the [readme](https://github.com/elkarbeenus/LakuenRecompBuilder#what-is-changed) lists them.
