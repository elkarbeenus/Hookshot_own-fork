LaküenRecomp v0.3.3 is one build for a PC, the Steam Deck and the Legion Go S. It is the first release that is playable on
the Legion Go S (mostly 30 fps, 60 with frame generation), and it brings the fork up to date with the last state of
NotRexed/Hookshot (`8b762704`, 2026-11-13; the upstream repository has not been reachable on GitHub since).

This release contains no game data, keys or executables: the AppImage is the builder, which builds the game on your PC from
your own copy. All of the recompilation work is NotRexed's and the Hookshot contributors'.

## For diagnosis
- **Master log:** after each run the builder sums up the game's last five logs in `lakuen_master_log.txt` in the game
  folder (frame rate over the run, RAM and swap, shaders, the costliest GPU work, warnings). **Open the master log** on the
  launcher's page shows it: one small file to send instead of a 16 MB log.
- **Create a report to send in:** one zip in Downloads with the summary, the master log, the log and the settings.
- **Effect finder** (Graphics tab): ranks the game's passes by GPU time and leaves any one out at once, to find what a
  graphical problem comes from. Each change goes into the log with the time.

## Builder
- **Updates from this fork's releases** only, never upstream's.
- **Transfer saves:** copy the save slots into the game from LaküenPlay / Lichii, an Eden-folder emulator, Eglantine or a
  folder, or out of it, with a backup first.
- **Time played** on the launcher's page. **Standby when done** instead of shutting down after a build.
- An own icon; the builder and the in-game menu say it is an own tuned fork of Hookshot.

## Graphics and performance
- Every shader is made at the start on every device (no stutter from shaders made in play).
- The two passes without which walls and textures turned white are always drawn. **Ground fog** and **Effect pass 1** can be
  left out (the handheld profiles do), **Shadow quality** goes down to Off.
- From upstream: fewer submits on the Steam Deck's APU (#2422), a **30 FPS** game frame rate cap with the game's real speed
  (#2582; with 2x frame generation that is 60), a **Texture detail** row (#2557), opaque ASTC textures as BC1 (half the
  memory, #2554), faster floating-point code in the translated game (#2433), staging memory kept and shared better (#2997,
  #2960), frame generation keeps the game's speed (#2531), and many fixes.
- Handhelds: less memory kept while RAM is short, textures at most 1024 px / 128 MB, the upload memory kept between areas.

## Known issues
- Busy areas (the open field) drop below 30 fps now and then on handhelds: the CPU records up to 2,800 draws a frame there.
- Some places look far too bright in a white haze (a fairy's fountain, interiors around the market).
- Rarely: glyph-like garbage in the dialogue history, black textures for a moment after the quick item selection (R1),
  shadows popping up with Shadow quality at Off.
