LaküenRecomp v0.2.0 brings this fork up to date with [NotRexed/Hookshot](https://github.com/NotRexed/Hookshot) (`ee29dd5`, 140 upstream commits since v0.1.0's base) and keeps this fork's own defaults for Linux on AMD RDNA2 (desktop RX 6000 cards, Steam Deck, Legion Go S).

This release contains no game data, keys or executables: the AppImage is the builder, which builds the game on your PC from your own copy. All of the recompilation work is NotRexed's and the Hookshot contributors'.

## From upstream

- **Faster updates and builds:** updates skip the lift and a second build in a work folder no longer translates the game again (#2324, #2674); Steam Deck APUs are detected and the game is compiled for Zen 2 (#2492).
- **Performance:** readbacks wait only for the part that writes their range back (#2602), capture buffers in size classes (#2437), texture shadow copies from cached RAM (#2314), 6 background workers on 16-thread CPUs (#2440), a dynamic texture budget for integrated GPUs (#2603), large ASTC textures as BC7 (#2226).
- **AMD:** shader translation fixes (#2457), storage buffers on 16-byte boundaries (#2442, from Fritchii), noperspective varyings (Royal Family Tomb water, #1830); RADV's mesh shaders off by default on Linux (#2362), as this fork already had for RDNA2.
- **Fixes:** ground garbling after minutes in one area (#2545), cyan after a pause in the background (#2154), Play from a desktop launcher no longer stopped by systemd (#2540), the Steam Controller's gyro when Steam starts the game (#2495), the time of day above a 60 fps cap (#2093).
- **Menu:** the Insert menu in 13 languages, German among them (#1864).

## Kept from this fork

- Low-end defaults on dedicated cards of 8 GB or less (VRAM compaction held at 90%, a 512 MB render target pool).
- Handheld defaults (texture limits, frame generation off on first start, VRAM compaction off on integrated GPUs).
- Steam / Gaming Mode fixes (the game's own SDL2 under Steam, controllers regardless of window focus, the launcher waits for the game), Valve controllers' gyroscope off without Steam, the sound cushion, dark native file choosers, lower build priority, the LaküenRecomp name.

Every change can be switched off with an environment variable in `hookshot_env.txt`; the [readme](https://github.com/elkarbeenus/Hookshot_own-fork#what-is-changed) lists them.

## Install

1. Start your LaküenRecomp builder and press **Update**, or download `LakuenRecomp-v0.2.0-x86_64.AppImage` below, `chmod +x` it and start it.
2. An existing game folder is updated in place; saves stay in `~/.local/share/hookshot`.
